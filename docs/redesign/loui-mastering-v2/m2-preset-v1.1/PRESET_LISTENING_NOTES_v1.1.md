## Scoring fields (per preset)

- **Loudness feel** — appropriate for the target platform?
- **Vocal clarity** — intelligible, present?
- **Harshness** — any 2–5 kHz glare / sibilance? (lower = better)
- **Low-end mud** — clean 100–300 Hz? (lower = better)
- **Stereo width** — wide enough / not fake?
- **Punch** — transient impact?
- **Listening fatigue** — tiring over 3+ min? (lower = better)
- **Mono compatibility** — survives phone/mono fold-down?
- **Preview vs Export** — consistent? (Y/N + Δ LUFS)

## Per-preset acceptance focus

- **AI Pop / KPOP Loud** — loud + bright but Harsh ≤ 2, no tearing.
- **YouTube Safe** — Fatigue ≤ 2 over a full listen.
- **Lofi Warm / Vintage Soft** — warm, not muddy; not over-compressed.
- **EDM Wide / Mono Safe Shorts** — Mono ≥ 4 (no bass loss on fold-down).
- **Ballad Vocal** — Vocal ≥ 4, Mud ≤ 2.
- **Piano Natural** — Punch ≥ 4 (dynamics preserved), no pumping.
- **AI Vocal Cleaner / Cymbal Smooth** — Harsh ≤ 2 while Vocal/Width intact.
- **Stereo Repair** — Mono = 5, no phasey artefacts.
