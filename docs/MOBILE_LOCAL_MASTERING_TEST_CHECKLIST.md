# 모바일 로컬 마스터링 — Android 실기기 테스트 체크리스트

목적: **Render 서버가 완전히 꺼져 있어도** Android 앱에서 `파일 선택 → 로컬 마스터링 →
미리듣기 → export/share`까지 정상 동작하는지 실기기로 검증한다. 목표는 **서버비 0원 + 모바일
테스트 통과**(고품질 완성형 아님 — MVP).

- 마스터링은 100% 기기 내부(WebView, Web Audio API)에서 처리된다. 서버/업로드/네트워크 없음.
- 각 항목은 **PASS / FAIL / BLOCKED**로 표기.
- 코드 변경 금지 — 검증 문서.

## 6. MVP 제한 (Android WebView 메모리 한계 고려)

> WebView(Chromium)에서 PCM float32 디코드 + 오프라인 렌더 버퍼(입력/EQ/마스터) + WAV 출력이
> 메모리를 곱절로 사용한다. 저사양 기기 OOM을 막기 위한 보수적 한계.

| 항목 | 값 | 코드 위치 |
|---|---|---|
| **권장 파일 길이** | **6분 이하** | `RECOMMENDED_DURATION_SEC` / `LARGE_DURATION_SEC` (`localMobileMastering.ts`) |
| **하드 길이 한계** | **15분 초과 거부** | `MAX_DURATION_SEC` |
| **경고 파일 크기** | **60MB 초과 → 경고(처리 가능)** | `LARGE_FILE_BYTES` (App.tsx 경고 + 엔진 warning) |
| **최대 파일 크기** | **150MB 초과 → 거부** | `MAX_FILE_BYTES` (App.tsx 시작 차단 + 엔진 가드) |
| 출력 포맷 | WAV 16-bit (단일 결과) | `encodeWav16` |
| 동시 실행 | 1개만 | App.tsx `busy` 가드 |

### 실패 시 사용자 메시지 (코드 기준)
| 상황 | 코드 | 메시지 |
|---|---|---|
| 디코드 불가/비오디오 | `FILE_DECODE_FAILED` | "이 파일 형식은 기기에서 열 수 없습니다. WAV / MP3 / M4A 파일을 사용해 주세요." |
| 메모리 부족(크기/길이/할당 실패) | `INSUFFICIENT_MEMORY` | "이 기기의 메모리로는 이 파일을 처리할 수 없습니다. 더 짧은 음원을 사용해 주세요." / "150MB가 넘는 파일은…" / "15분이 넘는 파일은…" |
| 내보내기 실패 | `EXPORT_FAILED` | "마스터링 결과를 저장하는 중 문제가 발생했습니다. 다시 시도해 주세요." |

| 백그라운드 전환 | (UI 가드) | "마스터링 중 앱이 백그라운드로 전환되어 중단되었습니다. 다시 시도해 주세요." |
| 동시 실행 | (UI 가드) | "현재 마스터링이 진행 중입니다. 완료된 후 다시 시도해 주세요." |

## 7. Go / No-Go

### ✅ Go (서버비 0원 + 모바일 테스트 통과)
- 1절 전부 PASS (서버 OFF + 비행기모드에서 마스터링→미리듣기→export 완주)
- 2~5절 주요 항목 PASS, 크래시/화이트스크린 0
- 6절 제한 안내가 의도대로 동작(거부/경고/메시지)

### ⛔ No-Go
- 서버 OFF 또는 비행기모드에서 마스터링 실패
- 외부(onrender.com) 호출 발생
- OOM 크래시(메시지 없이 앱 종료)
- 결과 무음/파탄, export/share 실패, 재실행 시 크래시
