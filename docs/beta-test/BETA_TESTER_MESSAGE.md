# 🎧 AIMASTER 베타 테스트 요청 — v3.4.1

안녕하세요!

지난 피드백 (보컬이 뭉개지고, 라디오처럼 들리고, 배경이 너무 커진다는 지적)
을 바탕으로 마스터링 엔진을 크게 개선했습니다. 이번 v3.4.1 버전을
실제 곡으로 테스트해주실 수 있을까요?

**테스트 목적**
"이전 버전과 비교해 실제로 좋아졌는가? 어떤 부분이 더 개선되어야 하는가?"
를 알고 싶습니다. **단순 "좋다 / 나쁘다"가 아니라, 어떤 부분이 어떻게
다른지** 알려주시면 가장 큰 도움이 됩니다.

---

## 1. 준비물

- **테스트할 곡 (1~3 곡 권장)**
  - 가능하면 **WAV 파일** (MP3/AAC 보다 훨씬 안정적인 결과를 보장합니다)
  - 가능하면 한 곡은 보컬이 분명한 곡 (예: 발라드, K-Pop)
  - 가능하면 한 곡은 비트가 강한 곡 (예: EDM, Hip-Hop)
- **이전 버전 결과** (있으시면)
  - 같은 곡으로 v3.3 이전 버전에서 마스터링한 결과 파일
  - 없으시면 새 버전 결과만 평가하셔도 OK

## 2. 테스트 시나리오

각 곡마다 **3회씩** 마스터링해주세요.

### 시나리오 A — 기본 KPOP 모드
- **모드**: KPOP Loud
- **레퍼런스**: 사용 안 함
- **목적**: 새 엔진의 보컬 보호가 KPOP 모드에서도 잘 작동하는지 확인
- **변경점**: ratio / attack / makeup gain / limiter level_in 이 자동으로
  보수화됩니다.  사용자는 별도 조작 없이 이전 버전과 같은 방식으로 사용.

### 시나리오 B — 추천 프리셋 사용
- **모드**: 선택 안 하고 **"장르 프리셋"** 화면으로 이동
- 자동 추천(💡 노란 박스)이 뜨면 그대로 적용 후 마스터링
- 또는 본인이 어울린다고 생각하는 프리셋 선택
- **목적**: 레퍼런스 없이도 좋은 결과가 나오는지 확인

### 시나리오 C — 레퍼런스 매칭
- **모드**: KPOP Loud (또는 곡과 어울리는 모드)
- **레퍼런스**: 본인이 좋아하는 발매된 곡 1개 (반드시 **마스터링된 곡**)
- 가능하면 같은 장르 / 비슷한 보컬 톤의 곡으로
- **목적**: Ozone 스타일 reference 매칭이 제대로 작동하는지 확인

## 3. 어떤 부분을 들어보세요

순서대로 들어보시면 가장 정확한 비교가 됩니다:

1. **메인 멜로디 / 보컬 부분**
   - 이전 버전 → 새 버전 → 레퍼런스 순서로 약 10초씩
2. **드럼 / 베이스가 강한 부분**
   - 같은 순서로 비교
3. **조용한 부분 (인트로 / 브릿지)**
   - 백그라운드 노이즈 / 룸 사운드가 부각되는지

## 4. 자주 발생하는 문제 vs 개선 항목

| 이전 v3.3 문제 | v3.4.1 에서 어떻게 개선되었는지 |
|----------------|------------------------------|
| 보컬이 뭉개짐 / 답답함 | 컴프레서 ratio ≤ 2.0, attack ≥ 25 ms 자동 적용 |
| 백그라운드가 너무 커짐 | Limiter level_in ≤ 0.5 dB, entry gain ≤ 6 dB 자동 캡 |
| 라디오처럼 평탄한 음질 | crest factor 자동 모니터링, brickwall 감지 시 경고 |
| 너무 눌린 느낌 | gain staging 단계 분산, 보정 패스가 단계적으로 |
| 레퍼런스 잘못 골라서 망함 | 레퍼런스 자동 검증 + 장르 mismatch 경고 |

## 5. 결과 파일 + 피드백 보내는 법

마스터링이 끝나면 결과창에서 다음 정보를 같이 보내주세요:

### 옵션 1 (가장 좋음): 디버그 번들
- 결과창의 **"디버그 번들 다운로드"** 버튼 클릭
- 생성된 zip 파일을 첨부 (오디오 파일 포함 X — 메타데이터만)

### 옵션 2: 피드백 폼만
- `docs/beta-test/FEEDBACK_TEMPLATE.md` 또는
  `docs/beta-test/feedback_template.json` 형태로 작성
- 결과 파일을 청취 후 USER_CHECKLIST 의 항목 채워서 회신

### 옵션 3: 자유 형식 (가장 빠름)
- 그냥 들어본 인상을 한국어로 자유롭게:
  - "보컬은 이전보다 선명한데 베이스가 좀 약해진 느낌"
  - "프리셋 자동 추천은 정확했는데 결과는 너무 보수적"
  - 같은 식으로 **"무엇이" "어떻게" 다른지** 한 줄 한 줄 적어주세요

## 6. 시간 부담

- 최소 테스트: **1 곡 × 3 시나리오 ≈ 15 분**
- 권장 테스트: **3 곡 × 3 시나리오 + 피드백 작성 ≈ 1 시간**

## 7. 문제 신고 / 충돌 발생 시

마스터링 중 앱이 충돌하거나 결과가 이상한 경우:
- **디버그 번들**을 꼭 같이 보내주세요 (input 메타데이터, 환경, ffmpeg 로그 포함)
- 충돌 시 보이는 에러 메시지 스크린샷
- 가능하면 OS / 앱 버전

## 8. 답변 기한

가능하면 **1주일 안에** 회신 부탁드립니다.
