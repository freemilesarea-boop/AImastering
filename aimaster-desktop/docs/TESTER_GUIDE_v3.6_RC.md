# 내부 RC 테스터 가이드 — v3.6.0-rc.1

> 안녕하세요. Louver Mastering AI v3.6.0-rc.1 내부 테스트에 참여해 주셔서
> 감사합니다.  이 문서는 **15분 안에** 설치 → 시나리오 1회 → 진단 리포트
> 송부까지 끝내실 수 있도록 짧게 정리되어 있습니다.

테스터 5분류 우선 모집 (한 사람이 여러 분류를 겸해도 됩니다):

1. **AI 음원 사용자** (Suno / Udio / 기타 AI 생성 트랙)
2. **KPOP 보컬 트랙** 위주 작업자
3. **플레이리스트 큐레이터** (여러 트랙을 batch 처리)
4. **저사양 Windows** 사용자 (RAM 8 GB / SSD 256 GB 이하)
5. **macOS** 사용자 (Apple Silicon / Intel)

---

## 1 · 설치

### Windows (NSIS installer)
1. CI 빌드에서 `Louver Mastering AI-Setup-3.6.0-rc.1.exe` 다운로드.
2. 더블 클릭 → "Windows 의 PC 보호" 화면에서 "추가 정보" → "실행".
3. 설치 위치 선택 (기본값 권장) → 완료.
4. 시작 메뉴 또는 바탕화면 바로가기로 실행.

> SmartScreen / Windows Defender 가 첫 실행을 막아도 정상입니다 — RC 빌드는
> 코드 서명을 받지 않은 상태입니다.  "추가 정보" → "실행" 만 누르세요.

### macOS (unsigned ZIP)
1. CI 빌드에서 `Louver Mastering AI-3.6.0-rc.1-arm64-mac.zip` (Apple
   Silicon) 또는 `…-x64-mac.zip` (Intel) 다운로드.
2. 압축 해제 → `.app` 을 `/Applications` 로 드래그.
3. **Finder 에서 우클릭 → "열기"** (더블 클릭하지 마세요 — Gatekeeper 가
   막습니다).  "확인되지 않은 개발자" 경고에서 "열기" 클릭.
4. (대안) Terminal:
   ```
   xattr -dr com.apple.quarantine "/Applications/Louver Mastering AI.app"
   ```

> macOS 자동 업데이트는 v3.6.x 정식 코드 서명 빌드 전까지는 작동하지
> 않습니다.  새 RC 가 나오면 수동으로 다시 받아주세요.

### Linux (AppImage)
1. `Louver Mastering AI-3.6.0-rc.1-linux-x86_64.AppImage` 다운로드.
2. `chmod +x "Louver Mastering AI-3.6.0-rc.1-linux-x86_64.AppImage"`.
3. 더블 클릭 또는 터미널에서 실행.

## 2 · 첫 실행 확인 (5분)

| 항목 | 어떻게 확인 |
|---|---|
| 앱이 켜진다 | 홈 화면이 보인다.  버전 표시가 **3.6.0-rc.1**. |
| FFmpeg 가 잡힌다 | 시스템에 ffmpeg 가 없는 환경에서도 분석이 시작되어야 합니다. |
| 라이선스 키 입력 없이 실행 | 이번 RC 부터는 라이선스 키 입력 화면 / "Free" 배지가 없습니다.  마스터링이 아무런 게이트 없이 바로 가능해야 합니다. |

문제 발생 시 → 아래 §4 진단 리포트 송부.

## 3 · 시나리오 (자유 순서, 각 5–10분)

다음 중 본인 환경에 맞는 항목을 **2개 이상** 진행해 주세요.  체크박스가
표시된 시나리오는 모든 테스터가 가능하면 한 번씩 해 주세요.

- [ ] **(필수) 짧은 트랙 1개** — 30초 미만 WAV 한 개를 드래그 → Balanced
      모드로 마스터링 → Preview 재생 → "마스터 WAV 저장".
- [ ] **(필수) 진단 리포트 다운로드** — 결과 페이지에서 "TXT 저장" /
      "JSON 저장" 둘 다 한 번씩.
- [ ] **AI 생성 트랙 1개** — Suno / Udio export.  결과 페이지가 어떤 자동
      보정이 적용되었는지 표시되는지 확인.
- [ ] **KPOP 보컬 트랙** — "KPOP Loud" 모드.  보컬이 묻히지 않는지 청취
      확인 (A/B 비교 토글).
- [ ] **플레이리스트 batch** — 5–10 곡을 동시에 큐에 넣고 일괄 처리.
- [ ] **장시간 트랙** — 8분 이상 WAV.  진행률이 끝까지 도달하는지.
- [ ] **한글 / 특수문자 파일명** — `한글_트랙 #2.wav`, `What is this?.mp3`
      등 파일명에 한글 / 띄어쓰기 / `#` / `?` 가 있는 케이스.  Preview /
      WAV 저장이 정상 작동하는지.
- [ ] **저사양 머신** — 8 GB RAM, SSD 256 GB.  마스터링 중 UI 가 멈추지
      않는지, 메모리 점유가 2 GB 이내로 유지되는지 (작업 관리자 확인).
- [ ] **Live LUFS / TP 미터** — Preview 를 재생할 때 우측 미터가 100 ms
      주기로 갱신되는지.

각 시나리오에서 발견한 이슈는:
1. 어떤 시나리오 / 어떤 파일에서
2. 어떤 메시지 / 화면이
3. 언제 (재현 가능한가)

…를 메모해 주세요.

## 4 · 진단 리포트 (Support Bundle) 송부

### 만드는 법
1. 결과 페이지 우측 상단 **"지원 진단 내보내기"** 버튼 클릭 (없으면 §6
   참고).
2. JSON 파일 저장 위치를 고르세요 (예: 바탕화면).
3. 파일명은 `aimaster-support-<timestamp>.json` 형식.

### 보내실 때 함께 적어주실 것
- 테스터 ID (받으신 invite 메일에 표시됨)
- 빌드 버전: `3.6.0-rc.1`
- OS / 아키텍처 (예: Windows 11 x64, macOS 14.4 arm64)
- 재현된 시나리오 짧은 메모 (1–2줄로 충분)

### 어디로 보내나
내부 Slack `#mastering-rc-test` 채널 또는 `qa@louver.<host>` 메일로 첨부.

> ⚠️ 진단 리포트에는 사용자의 절대 경로 / 파일 본문이 포함되지 않습니다
> (`~`로 익명화).  파일명은 포함되니 민감하면 별도로 알려주세요.
> (라이선스 키는 이번 RC 에서 사용하지 않으므로 처음부터 포함될 일이
> 없습니다.)

## 5 · 자주 묻는 것 (FAQ)

**Q. 마스터링 도중에 앱이 멈춥니다.**
A. 작업 관리자에서 메모리 점유를 확인해주세요.  8 GB 미만이면 longer
files 시나리오를 잠시 보류하고 다른 시나리오부터 진행해주세요.  무조건
진단 리포트를 첨부해 주시면 분류해 드립니다.

**Q. Preview 가 재생이 안 됩니다.**
A. 파일명에 `#` / `?` / 한글이 들어가 있나요?  v3.6.0-rc.1 부터는
지원되어야 하는데, 만약 막히면 그게 곧 회귀이므로 진단 리포트
보내주세요.

**Q. macOS 에서 "손상된 앱" 으로 떠요.**
A. quarantine 속성 때문입니다.  §1 macOS 절차의 `xattr` 명령을
실행해주세요.

**Q. Live LUFS 미터가 안 움직여요.**
A. Preview 를 **재생** 중이어야 합니다 (일시 정지 시 미터도 멈춤).
재생 중에도 안 움직이면 진단 리포트 부탁드립니다 — `worklet` 카테고리에
실패가 잡혀 있을 거예요.
