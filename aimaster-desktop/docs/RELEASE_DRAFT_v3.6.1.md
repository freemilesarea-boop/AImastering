# LV DAW v3.6.1

이름이 바뀌었습니다 — **Louver Mastering AI → LV DAW**. 프로그램이 마스터링 도구
하나가 아니라 멀티트랙 DAW로 자란 게 이유입니다.

그리고 이번 빌드에서 **두 갈래로 따로 자라던 코드가 하나로 합쳐졌습니다.** 지금까지는
스튜디오 모듈 수트가 있는 빌드와 DAW가 있는 빌드가 따로 있었습니다. 이제 한 앱입니다.

## 다운로드

| 내 컴퓨터 | 받을 파일 |
|---|---|
| **맥 (M1·M2·M3·M4)** | `LV DAW-3.6.1-arm64.dmg` (또는 `.zip`) |
| **맥 (인텔)** | `LV DAW-3.6.1-x64.dmg` (또는 `.zip`) |
| **윈도우** | `LV DAW-Setup-3.6.1.exe` |
| **리눅스** | `LV DAW-3.6.1-linux-x86_64.AppImage` (데비안·우분투 계열은 `.deb`) |

맥에서 어느 쪽인지 모르겠으면: 화면 왼쪽 위 사과 → **이 Mac에 관하여** → 칩 항목에
`Apple M…` 이라고 쓰여 있으면 arm64, `Intel` 이면 x64 입니다.

### ⚠️ 맥에서 처음 열 때

이 빌드는 **애플 공증(notarization)을 받지 않았습니다.** 그래서 그냥 더블클릭하면
"손상되었기 때문에 열 수 없습니다" 또는 "확인되지 않은 개발자" 경고가 뜹니다.
앱이 망가진 게 아니라 서명이 없어서 나오는 경고입니다.

여는 방법 — 앱을 **응용 프로그램** 폴더로 옮긴 뒤 터미널에서 한 번만:

```bash
xattr -dr com.apple.quarantine "/Applications/LV DAW.app"
```

그 다음부터는 평소처럼 열면 됩니다. 같은 이유로 **맥은 자동 업데이트가 아직 안 됩니다** —
공증된 앱이어야 교체가 가능합니다. 윈도우·리눅스는 자동 업데이트가 붙어 있습니다.

### ⚠️ 윈도우에서 처음 열 때

SmartScreen이 "Windows의 PC 보호" 경고를 띄웁니다. **추가 정보 → 실행**을 누르면
설치됩니다. 코드 서명 인증서가 없어서 나오는 경고입니다.

## 이번 빌드에 들어간 것

### 하나가 된 앱

스튜디오(마스터링 모듈 수트)와 DAW(멀티트랙 편집·믹스)가 한 빌드에 있습니다.
홈에서 **스튜디오** 버튼으로 마스터링 체인을, 오른쪽 위 **DAW** 버튼으로
멀티트랙 워크스페이스를 엽니다.

### 소리가 터지던 리버브

**Spring Reverb가 임펄스 하나에 출력을 3.6조까지 올리던 문제**를 고쳤습니다.
입력 대비 +226 dB — 스피커를 부수고 모니터하던 귀를 다치게 할 수 있는 값이었습니다.

원인은 올패스 필터였습니다. 올패스가 이득 1인 건 분자와 분모에 같은 딜레이가 있어
극점과 영점이 지워지기 때문인데, 소수점 샘플을 주면 보간이 일어나 그 상쇄가 깨집니다.
그런 단이 피드백 루프 안에 여덟 개 있었습니다. 딜레이를 정수 샘플로 맞추고, 분산
체인을 루프 밖으로 뺐습니다. 지금은 다른 리버브들과 같은 범위(−26.7 dB)에서 감쇠합니다.

### 파일에 기록되는 제작 이력

내보내는 모든 파일에 **AI를 어디에 썼는지, 무엇을 원곡으로 삼았는지, 어떤 권리로
쓰는지**가 기록됩니다. WAV는 LIST/INFO · Broadcast Wave `bext` · 자체 JSON 청크로,
MP3 프리뷰는 ID3v2.4로 들어갑니다. 유통사가 업로드할 때 묻는 것들이고, 6개월 뒤
기억으로 답하기엔 비싼 것들입니다.

이건 Content ID를 피하는 수단이 **아닙니다.** 지문 매칭은 오디오를 읽지 태그를 읽지
않습니다. 이건 클레임이 걸렸을 때 답할 근거입니다.

### 마스터 저장에 제한 없음

라이선스·체험판 게이트가 코드에서 제거됐습니다. 모든 형식으로 제한 없이 저장됩니다.

### 디더

비트 심도를 줄일 때 디더가 실제로 걸립니다(TPDF·노이즈 셰이핑 선택 가능).
체인이 디더를 걸면 파일 writer는 물러나므로, 노이즈 바닥이 두 번 얹히지 않습니다.

## 알려진 제한

- **맥·윈도우 바이너리는 리눅스 컨테이너에서 실행 검증하지 못했습니다.** CI가
  아키텍처 게이트를 통과시켜 빌드한 것까지는 확인됐고, 리눅스 패키지는 직접 실행해
  화면이 뜨는 것까지 봤습니다.
- **맥 자동 업데이트 없음** (공증 전까지).
- 스튜디오에 저장된 설정이 없는 곡은 기존 Python 엔진으로 렌더됩니다. 이 경로에서는
  랙에서 조정한 값이 파일에 반영되지 않습니다. 스튜디오에서 한 번 저장하면
  Rust 체인이 그대로 렌더합니다.
