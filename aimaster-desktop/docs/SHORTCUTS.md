# 키보드 단축키 (DAW 레이아웃)

Cubase 계열 DAW 단축키를 그대로 옮겨온 전역 키보드 레이어입니다.
앱 어디서나 동작하며, 입력창(`input` / `textarea` / `contenteditable`)에
포커스가 있을 때는 비활성화됩니다.

앱에서 **`?` 또는 `F1`** 을 누르면 같은 표가 오버레이로 뜹니다. 그 오버레이는
`src/renderer/shortcuts/definitions.ts` 에서 생성되므로 구현과 절대 어긋나지
않습니다.

- 구현: `src/renderer/shortcuts/` (`keys.ts` · `definitions.ts` · `commands.ts` · `useDawShortcuts.ts`)
- 상태: `src/renderer/stores/workspaceStore.ts`
- UI: `src/renderer/components/daw/`
- 테스트: `pnpm --filter @aimaster/desktop test:shortcuts`

`Mod` 은 macOS 에서 `Cmd`, Windows/Linux 에서 `Ctrl` 입니다. 매칭은
`KeyboardEvent.code`(물리 키) 기준이라 넘패드와 자판 상단 숫자열이 구분되고,
macOS 의 `Option+X` 처럼 조합 문자가 나오는 경우에도 정확히 동작합니다.

## 1. 프로젝트 및 파일

| 기능 | 단축키 | 이 앱에서의 동작 |
|---|---|---|
| 새 프로젝트 생성 | `Mod+N` | 세션 초기화 후 홈으로 (큐 · 결과 · 리비전 삭제) |
| 프로젝트 열기 | `Mod+O` | 오디오 파일 열기 → 큐에 추가 |
| 세션 열기 | `Mod+Shift+O` | `.louisession` 불러오기 (소스 · 설정 복원) |
| 저장 | `Mod+S` | 현재 세션을 `.louisession` 으로 저장 |
| 다른 이름으로 저장 | `Mod+Shift+S` | 세션 저장 (항상 저장 위치를 다시 물음) |
| 내보내기 | `Mod+Alt+E` | 마스터 WAV 내보내기 (라이선스 필요) |
| 프로젝트 설정 | `Shift+S` | 설정 페이지 |

## 2. 재생 및 탐색

| 기능 | 단축키 | 이 앱에서의 동작 |
|---|---|---|
| 재생 / 정지 | `Space` | 프리뷰 재생 · 일시정지 |
| 녹음 시작 | `Numpad *` | **해당 없음** — 녹음 트랙이 없습니다 |
| 재생 위치 0점 | `Numpad .` · `Home` | 0초(루프 ON 이면 루프 시작점)로 이동 |
| 메트로놈 | `C` | **해당 없음** — 템포/클릭 트랙이 없습니다 |
| 루프 on/off | `Numpad /` | 루프 재생 토글 (구간이 없으면 전체 구간으로 무장) |
| 좌측 루프 포인터 | `Numpad 1` | 루프 시작점으로 이동 |
| 우측 루프 포인터 | `Numpad 2` | 루프 끝점으로 이동 |
| 가로 축소 / 확대 | `G` / `H` | 파형 가로 줌 (재생 헤드 기준, ×1~×64) |
| 세로 축소 / 확대 | `Shift+G` / `Shift+H` | 파형 진폭 줌 (×1~×8) |

## 3. 메인 툴바 (자판 상단 숫자)

| 키 | 툴 | 파형 레인에서의 동작 |
|---|---|---|
| `1` | 선택 | 클릭 → 재생 위치 이동 |
| `2` | 범위 선택 | 드래그 → 구간 선택 (`Shift+드래그` 는 어느 툴에서나 동일) |
| `3` | 자르기 | 구간 안 클릭 → 그 지점에서 분할 |
| `4` | 붙이기 | **해당 없음** — 이벤트 트랙이 없습니다 (툴만 전환) |
| `5` | 삭제 | 클릭 → 선택/루프 구간 해제 |
| `6` | 줌 | 클릭 → 확대, `Alt+클릭` → 축소 |
| `7` | 뮤트 | 클릭 → 프리뷰 뮤트 토글 |
| `8` | 연필 | **해당 없음** — 오토메이션 레인이 없습니다 (툴만 전환) |
| `9` | 스크럽 | 드래그 → 재생 헤드를 따라가며 듣기 |

## 4. 편집 및 트랙 조작

| 기능 | 단축키 | 이 앱에서의 동작 |
|---|---|---|
| 실행 취소 | `Mod+Z` | 마스터링 설정 변경 되돌리기 (실시간 DSP 즉시 반영) |
| 다시 실행 | `Mod+Shift+Z` · `Mod+Y` | 되돌린 설정 다시 적용 |
| 복사 / 붙여넣기 | `Mod+C` / `Mod+V` | 현재 마스터링 설정 복사·적용 (텍스트를 선택해 둔 상태의 `Mod+C` 는 일반 복사) |
| 연속 복사 (Duplicate) | `Mod+D` | 현재 결과를 새 리비전으로 복제 |
| 반복 (Repeat) | `Mod+K` | 현재 설정으로 다시 마스터링 실행 |
| 커서 위치에서 자르기 | `Alt+X` | 재생 위치에서 선택/루프 구간 분할 |
| 스냅 on/off | `J` | 1초 그리드 + 섹션 경계 스냅 |
| 솔로 | `S` | 원본 솔로 — 마스터 체인 바이패스 |
| 뮤트 | `M` | 프리뷰 출력 뮤트 |
| 모든 Solo/Mute 해제 | `Alt+S` · `Alt+M` | 뮤트 + 바이패스 해제 (트랜스포트 바 버튼 `Alt+클릭` 도 동일) |
| 선택 구간에 루프 맞추기 | `P` | 선택 구간 → 루프 구간 (선택이 없으면 전체) |

## 5. 창 및 패널

| 기능 | 단축키 | 이 앱에서의 동작 |
|---|---|---|
| 믹스콘솔 | `F3` | 하단 믹스콘솔 (EQ/DYN/IMAGER/LIMITER 바이패스 + 마스터) |
| 트랜스포트 Panel | `F2` | 하단 트랜스포트 바 (파형 · 루프 · 툴) |
| MIDI 피아노 롤 | `Enter` | **해당 없음** — MIDI 이벤트가 없습니다 |
| 하단 에디터 패널 | `Mod+Alt+B` | 하단 존 전체 열기/닫기 |
| VST 에디터 | `F11` | 고급 파라미터 패널 |
| MediaBay | `F5` | 스타일 · 라우드니스 타깃 · 리미터 프리셋 브라우저 |
| 좌측 인스펙터 | `Alt+I` | 소스 · 타깃 · 루프 · 툴 상태 패널 |
| 우측 랙(Zone) | `Mod+Alt+R` | 우측 세밀 조정 패널 |
| 단축키 도움말 | `?` · `F1` | 이 표를 오버레이로 표시 |

## Cubase 표와 달라진 점

원본 표를 그대로 넣으면 충돌하거나 동작할 수 없는 항목이 있어 두 곳만
조정했습니다.

1. **하단 에디터 패널**: Cubase 는 `Ctrl+Alt+E` 지만 이 앱에서는 같은 키가
   "내보내기"입니다. 하단 존 토글을 `Mod+Alt+B` 로 옮겼습니다.
2. **세션 열기**: Cubase 에 대응 항목이 없어 `Mod+Shift+O` 를 새로
   추가했습니다. `Mod+O` 는 이 앱의 실제 진입점인 오디오 파일 열기입니다.

**해당 없음** 으로 표시된 5개(녹음 · 메트로놈 · 붙이기 · 연필 · 피아노 롤)는
키를 눌러도 조용히 무시되지 않고, 왜 동작하지 않는지와 가장 가까운 대체
동작을 토스트로 알려줍니다.
