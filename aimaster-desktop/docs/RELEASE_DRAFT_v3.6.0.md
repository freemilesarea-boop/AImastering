# Louver Mastering AI v3.6.0

AI 음원을 기성 음원 질감으로 만드는 데 필요한 기능들을 모은 1차 가이드 빌드입니다.

## 다운로드

| 내 컴퓨터 | 받을 파일 |
|---|---|
| **맥 (M1·M2·M3·M4)** | `Louver Mastering AI-3.6.0-arm64.zip` |
| **맥 (인텔)** | `Louver Mastering AI-3.6.0-x64.zip` |
| **윈도우** | `Louver Mastering AI-Setup-3.6.0.exe` |
| **리눅스** | `.AppImage` (데비안·우분투 계열은 `.deb`) |

맥에서 어느 쪽인지 모르겠으면: 화면 왼쪽 위 사과 → **이 Mac에 관하여** → 칩 항목에
`Apple M…` 이라고 쓰여 있으면 arm64, `Intel` 이면 x64 입니다.

### ⚠️ 맥에서 처음 열 때

이 빌드는 **애플 공증(notarization)을 받지 않았습니다.** 그래서 그냥 더블클릭하면
"손상되었기 때문에 열 수 없습니다" 또는 "확인되지 않은 개발자" 경고가 뜹니다.
앱이 망가진 게 아니라 서명이 없어서 나오는 경고입니다.

여는 방법 — 앱을 **응용 프로그램** 폴더로 옮긴 뒤 터미널에서 한 번만:

```bash
xattr -dr com.apple.quarantine "/Applications/Louver Mastering AI.app"
```

그 다음부터는 평소처럼 열면 됩니다.

### ⚠️ 윈도우에서 처음 열 때

SmartScreen이 "Windows의 PC 보호" 경고를 띄웁니다. **추가 정보 → 실행**을 누르면
설치됩니다. 코드 서명 인증서가 없어서 나오는 경고입니다.

## 이번 빌드에 들어간 것

### AI 음원 특유의 문제를 겨냥한 기능

- **고역 재생성 (Top Rebuild)** — AI 보컬의 "물먹은 듯 번들거리는" 고음을 걷어내고,
  멀쩡한 중음에서 새 고음을 만들어 그 자리를 채웁니다. 고음을 *더하는* 엑사이터로는
  고칠 수 없는 문제입니다 — 번들거림이 그대로 밑에 남으니까요.
- **노이즈 게이트 (Hiss Gate)** — 인트로·아웃트로에서만 들리는 "츠으으" 전자 잡음을
  제거합니다. 음악이 있는 곳은 건드리지 않아, 고음을 깎는 EQ와 달리 곡의 화사함이
  남습니다.
- **AI 보컬 질감 복구 프리셋** — 위 기능들을 한 번에 걸어주는 프리셋.
  실측 −20.5 dB(12 kHz 아티팩트) / −1.4 dB(4.5 kHz 목소리).

### 곡마다 다른 설정

곡을 열면 프로그램이 **음량·크레스트·음색 곡선·고역 컷오프·스테레오 폭·저역 상관도·
잡음 바닥**을 측정하고, 그 곡에 맞춰 설정을 조정합니다. 무엇을 재서 무엇을 바꿨는지
각 모듈 패널에 한국어로 적혀 있습니다.

특히 **노이즈 게이트 기준선**은 고정값으로는 절대 맞출 수 없는 값이라, 곡의 가장
조용한 구간에서 직접 재서 정합니다.

### 초심자용

- **추천 설정** — 24개 모듈 전부에 시작값과 그 이유가 붙어 있습니다.
  절반은 "이건 꺼두세요"이고, 왜 꺼야 하는지도 적혀 있습니다.
- **전체 한글 표기** — 모든 모듈·파라미터에 한국어 이름과 설명.
- **전체 시각화** — 모든 모듈이 자기가 무엇을 하는지 그림으로 보여줍니다.

### 작업 흐름

- **곡별 설정 저장** — 스튜디오에서 조정한 값이 곡에 붙어 저장됩니다. 앱을 껐다 켜도
  남습니다.
- **일괄 마스터링** — 곡 20개까지 올리고, 곡마다 따로 조정해 저장한 뒤, 마지막에
  공통 프리셋 하나를 골라 한 번에 추출. 곡에서 직접 조정한 모듈은 그 프리셋이
  덮어쓰지 않습니다.
- **레퍼런스 매칭** — 닮고 싶은 곡을 불러오면 그 곡의 음색 균형을 측정해 맞춰줍니다.

### 고쳐진 것

- 리미터의 **Target LUFS**가 아무 데도 연결되어 있지 않던 문제 (프리뷰와 추출물이
  6~10 dB 어긋나 있었습니다)
- 소리를 크게 만드는 **Drive** 컨트롤이 UI에 아예 없던 문제
- 출력 게인이 리미터 **뒤**에 있어 천장(−1.0 dBTP)을 넘길 수 있던 문제
- 고역 재생성의 지지직 잡음 (에일리어싱 −38 dB → −90 dB)
- 랙이 4개 모듈을 "꺼짐"으로 잘못 표시하던 문제

## 알려진 제약

- **맥·윈도우 코드 서명 없음** — 위의 경고 회피 방법을 참고하세요.
- **리눅스는 x64만** — ARM 리눅스 빌드는 없습니다.
- **자동 업데이트는 서명된 빌드에서만** 동작합니다. 이 빌드는 수동으로 받아야 합니다.
- 추천값은 배급 규격(스포티파이·애플뮤직 등 공개 사양)과 일반적인 상업 팝 관행에
  근거합니다. **특정 차트 곡을 측정한 값이 아닙니다.** 실제로 좋아하는 곡의 음색을
  따라가고 싶으면 **레퍼런스 매칭**에 그 곡을 넣으세요 — 그게 훨씬 정확합니다.

## 검증

Rust DSP 231개 + 데스크톱 385개 자동 테스트 통과. 오디오 관련 주장은 전부 실제
WASM 체인에 소리를 통과시켜 측정한 값입니다.
