# Exports only a test reaches — the baseline this suite ratchets down.
#
# `no export is left with nothing referencing it` judges liveness over
# `find src scripts`, so a SELFTEST importing the thing it tests counts as a
# caller and the export reads as live.  A test vouching for its own subject is
# the same shape as a check that measures nothing: it passes, and it guards
# nothing.  Measured the day this file was written, 244 exports were reached
# from a test and from nowhere else.
#
# Some belong here for good.  `resetDecodeContext`, `resetFailureLogForTests`
# and `resetPipelineWarningsForTests` say in their own names that a test is
# who they are for.  Most do not: `saveLayout`, `removeLayout`, `findLayout`
# and `describeLayout` are a saved-workspace-layout feature that was written,
# tested, and never connected to a single component — while the zoom slots
# beside them in the same module are wired into `dawStore`.
#
# The rule: this list may SHRINK and may not GROW.  Wire an export up or take
# it out, then take its line out of here.  A new line is a new export that
# only its own test can reach, and the suite says so by name.
#
# One `file::name` per line, sorted.
