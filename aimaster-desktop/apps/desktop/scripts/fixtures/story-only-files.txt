# The report used to print the list and stop there, which left nineteen files
# looking identical.  They are not: one group is waiting on a product
# decision, one exists so a story can run without an engine, and one is a
# feature that describes itself as always-on and is wired to nothing.  That
# last group is the one worth reading, and it was invisible in a flat list.
#
# Format:  <path>  <group>
#
# Groups

# awaiting-product-decision
#   The five bespoke per-module parameter panels and the controls they are
#   built from.  The app renders the generic panel instead.

#   imports none of them — the slide-over is live, but `LouiPresetSlideOver`
#   is its only caller.  Adopt them or delete them; until then they are
#   known, not forgotten.
#

#   Correctly story-only: these exist so a story renders without an audio
