# 개인정보 / 데이터 수집 노트 (Android 테스트 앱)

`com.louver.mastering.mobile`. Play **Data Safety** 양식과 개인정보처리방침 작성을
위한 데이터 흐름 정리. (결제/계정/로그인 **없음**, 개인식별정보 **수집 안 함**)

## 1. 개인정보처리방침 필요 여부
- **필요함.** 앱이 사용자 **오디오 파일을 서버로 업로드**하므로 Play 정책상
  개인정보처리방침 URL이 요구됨. 공개 호스팅된 URL을 Play Console에 등록해야 함.

## 2. 수집·전송 데이터 목록
| 데이터 | 수집/전송 | 목적 | 보관 | 비고 |
|---|---|---|---|---|
| **오디오 파일(업로드)** | 서버로 전송(HTTPS) | 마스터링 처리 | **임시**(서버 `JOB_TTL_SECONDS`, 기본 1h 후 삭제) | 사용자가 선택한 파일. 원본 파일명은 서버에 저장하지 않음 |
| **마스터링 옵션** | 전송 | 처리 파라미터(style/LUFS/TP/mode) | 작업 동안 | 개인정보 아님 |
| **오류 리포트** | 전송(`/v1/error-reports`) | 안정성 개선/관리자 알림 | 서버 로그 | app_version, platform, step, error_code, **정제 메시지**, file_meta(확장자/크기/타입), 타임스탬프. **API 키·원본 파일명·PII 제외**, 접수번호 발급 |
| **요청 메타/서버 로그** | 서버측 | 운영/디버깅 | 로그 보존 정책 | IP 등 표준 웹 로그 |
| 위치/연락처/카메라/마이크/광고ID | **수집 안 함** | — | — | 미사용 |
| 계정/이메일/결제 | **수집 안 함** | — | — | 로그인·결제 없음 |

## 3. 단말 내 저장
- 결과 WAV/MP3는 사용자가 **저장** 시 단말 Downloads(또는 앱 저장소 폴백)에 기록.
  앱이 외부로 전송하지 않음(공유는 사용자가 명시적으로 선택한 앱으로만).

## 4. 보안
- 모든 서버 통신 **HTTPS**. cleartext(http) 비활성.
- 서버 인증은 **`X-API-Key` 헤더**(쿠키 미사용). 오류 리포트·로그에서 **키 마스킹**.

## 5. Play Data Safety 매핑(요약 답안)
- 데이터 수집: **예** — "오디오"(앱 기능: 처리), "앱 활동/진단"(오류 리포트).
- 데이터 공유(제3자): **아니오**(서버는 자체 처리 백엔드).
- 전송 중 암호화: **예**.
- 사용자 데이터 삭제 요청 방법: 업로드 음원은 **TTL 자동 삭제**; 별도 식별정보 없음.
- 계정 생성: **없음**.

## 6. 개인정보처리방침 초안(요지)
> Loui Mastering(테스트)은 사용자가 선택한 오디오 파일을 마스터링 처리를 위해
> HTTPS로 서버에 업로드합니다. 업로드된 파일은 처리 완료 후 일정 시간(기본 1시간)
> 내 자동 삭제되며, 영구 저장하지 않습니다. 앱은 로그인·결제·위치·연락처 등
> 개인정보를 수집하지 않습니다. 안정성 개선을 위해 오류 발생 시 앱 버전·플랫폼·
> 오류 코드·정제된 오류 메시지 등 **비식별 진단 정보**를 전송하며, 여기에는 원본
> 파일명·API 키·개인정보가 포함되지 않습니다. 문의: (이메일).
>
> 실제 게시 전 법무 검토 및 호스팅 URL 확정 필요.
