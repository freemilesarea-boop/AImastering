# 모바일 테스트 앱 수동 검증 체크리스트 (M3)

`apps/mobile` 단계형 플로우(서버 설정 → 파일 → 분석 → 마스터링 → 결과)의
실기/웹 수동 검증 항목. 서버는 M0 API(`services/mastering-api`, Render 등) 사용.

## 0. 준비
- [ ] 서버 API 배포됨(`/healthz` 200). 키 사용 시 `MASTERING_API_KEY` 설정.
- [ ] 웹 미리보기: `pnpm --filter @aimaster/mobile dev` → 브라우저에서 플로우 점검.
- [ ] Android 실기:
  - [ ] `apps/mobile/.env` 에 `VITE_MASTERING_API_URL`(+ 필요 시 `_API_KEY`) 설정.
  - [ ] `pnpm --filter @aimaster/mobile build && npx cap sync android`
  - [ ] `cd android && ./gradlew assembleDebug` → APK 사이드로드 또는 Android Studio 실행.

## 1. 서버 설정 화면
- [ ] env 미설정 시 노란 경고(“서버 주소가 설정되지 않았습니다”)가 보인다.
- [ ] env 설정 시 “빌드 env에 서버가 설정되어 있습니다” 안내가 보인다.
- [ ] URL이 비었거나 `http(s)://` 형식이 아니면 “계속” 버튼이 비활성.
- [ ] 잘못된 URL 입력 시 인라인 에러 메시지가 뜬다.
- [ ] API Key 입력란은 password 마스킹된다.
- [ ] “적용될 주소”에 정규화된 URL(끝 슬래시 제거)이 표시된다.
- [ ] 유효 URL 입력 후 “계속” → 파일 단계로 이동.

## 2. 파일 선택
- [ ] “파일 선택” 탭 → Android 문서 선택기 열림(권한 팝업 없이 SAF 동작).
- [ ] wav/mp3/flac/m4a 선택 가능.
- [ ] 선택 후 파일명/크기(MB)/MIME 카드가 표시된다.
- [ ] 파일 선택 전 “다음” 버튼 비활성, 선택 후 활성.
- [ ] 취소(파일 미선택)해도 앱이 멈추지 않는다.
- [ ] 상단 스텝퍼에서 이전 단계(서버)로 되돌아갈 수 있다.

## 3. 분석 (선택)
- [ ] “분석 실행” → 스피너(“원본 분석 중…”) 표시.
- [ ] 성공 시 핵심 수치(key/value) 목록 표시.
- [ ] “원본 JSON 보기/숨기기” 토글 동작.
- [ ] 분석 없이 “마스터링으로” 진행 가능(선택 사항).
- [ ] 서버 오류 시 빨간 에러 박스 + “분석 다시 시도” 버튼 → 재시도 동작.

## 4. 마스터링 실행 + 진행률
- [ ] 스타일 드롭다운, 목표 LUFS/True Peak 슬라이더 조작 가능(드래그 시 페이지 스크롤 안 튐).
- [ ] 파일 없으면 “먼저 파일을 선택하세요” 안내 + 시작 버튼 비활성.
- [ ] “마스터링 시작” →
  - [ ] **업로드 중**: 스피너 + “큰 파일은 시간이 걸릴 수 있어요…” 안내(앱이 멈춘 것처럼 보이지 않음).
  - [ ] **처리 중**: 진행률 바(%) + 단계 텍스트가 갱신된다.
  - [ ] **내려받는 중**: “결과 내려받는 중…” 표시.
  - [ ] 항상 “경과 Ns” 타이머가 증가한다.
- [ ] 진행 중 “취소” → 즉시 옵션 화면으로 복귀, 이후 결과가 덮어쓰이지 않는다.
- [ ] 진행 중에는 “뒤로” 비활성.
- [ ] 서버/네트워크 오류 시 에러 박스 + “마스터링 다시 시도” → 재시도 동작.
- [ ] 완료 시 자동으로 결과 화면으로 이동.

## 5. 결과 (미리듣기 + 저장/공유)
- [ ] **마스터(WAV)** 항목: 오디오 플레이어로 재생됨(Android WebView).
- [ ] **프리뷰(MP3)** 항목: 있으면 별도 플레이어 + 버튼, 없으면 “제공되지 않았습니다” 안내.
- [ ] master/preview 각각 “저장/공유” → 네이티브 공유 시트 열림(파일 첨부됨).
- [ ] 웹에서는 저장/공유가 브라우저 다운로드로 동작.
- [ ] 공유 실패 시 에러 박스 표시.
- [ ] “새 파일로 다시” → 파일 단계로 초기화(이전 결과 사라짐).

## 6. 모바일 UX / 안정성
- [ ] 상단 헤더/스텝퍼는 고정, 본문만 스크롤된다.
- [ ] 하단 액션 바는 고정되고 safe-area(제스처 바) 침범 없이 탭 가능.
- [ ] 노치/홀펀치 기기에서 상단 콘텐츠가 가리지 않음(safe-area-top).
- [ ] 모든 버튼 터치 영역 ≥ 48px, 입력 포커스 시 화면 확대(zoom) 없음.
- [ ] 긴 본문에서 과도한 rubber-band/바운스 없이 스크롤(overscroll-behavior).
- [ ] 가로/세로 회전, URL 바 출몰에도 레이아웃이 깨지지 않음(100dvh).
- [ ] 콜드 스타트/반복 실행 시 크래시 없음.

## 7. 에러/안내 메시지
- [ ] 서버 URL 미설정 상태로 분석/마스터 시도 시 명확한 메시지(“API URL이 설정되지 않았습니다…”).
- [ ] 잘못된 API Key(401 등) 시 상태코드 포함 에러가 보인다.
- [ ] 네트워크 끊김 시 에러 박스 + 재시도로 복구 가능.

## 8. 회귀 (개발자)
- [ ] `pnpm --filter @aimaster/mobile build` 통과.
- [ ] `npx cap sync android` 통과(플러그인 3종 인식).
- [ ] `pnpm --filter @aimaster/desktop typecheck && build` 통과(데스크톱 무영향).
