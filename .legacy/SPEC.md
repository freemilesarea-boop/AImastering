| 항목 | 내용 |
|------|------|
| 제품명 | AImastering |
| 타깃 | 인디 음악가, 유튜버, 팟캐스터, 소규모 스튜디오 |

## 2. 기능 명세

### 2.1 파일 관리
- [ ] WAV 파일 드래그 앤 드롭 업로드
- [ ] 파일 탐색기를 통한 파일 선택
- [ ] 업로드 파일 검증 (포맷, 샘플레이트, 비트뎁스)
- [ ] 최근 파일 목록 (최대 10개)
- [ ] 배치 처리 (복수 파일 순차 처리)

### 2.2 오디오 분석 (Pre-Mastering Analysis)
- [ ] LUFS (Integrated, Short-term, Momentary) 측정
- [ ] True Peak 측정
- [ ] Dynamic Range (LRA, DR) 측정
- [ ] 주파수 스펙트럼 분석 (저/중/고역 밸런스)
- [ ] 클리핑 검출
- [ ] 분석 결과 리포트 생성

### 2.3 마스터링 프로세싱
- [ ] YouTube Music 대응형 마스터링 프로필 (기본값)
  - Integrated LUFS 타깃: -14 LUFS
  - True Peak 한계: -1.0 dBTP
- [ ] 사용자 정의 프로필 지원
- [ ] 2-pass loudnorm 처리 (FFmpeg 기반)
- [ ] EQ 처리 (고역 공기감, 저역 정리)
- [ ] 멀티밴드 컴프레션 (Python/librosa)
- [ ] 리미터 (True Peak 보호)
- [ ] 스테레오 이미징
- [ ] 처리 진행률 실시간 표시

### 2.4 QC (Quality Control) 검사
- [ ] 마스터링 전/후 비교 분석
- [ ] 플랫폼별 라우드니스 기준 준수 여부 체크
  - YouTube Music: -14 LUFS / -1.0 dBTP
  - Spotify: -14 LUFS / -1.0 dBTP
  - Apple Music: -16 LUFS / -1.0 dBTP
  - Tidal: -14 LUFS / -1.0 dBTP
- [ ] 클리핑 감지
- [ ] QC 리포트 PDF 내보내기
- [ ] 합격/불합격 판정

### 2.5 출력
- [ ] WAV 파일 내보내기 (16bit/44.1kHz, 24bit/48kHz 등)
- [ ] FLAC 파일 내보내기
- [ ] MP3 파일 내보내기 (320kbps)
- [ ] 출력 폴더 지정
- [ ] 파일명 패턴 지정 (원본명_mastered 등)

### 2.6 라이센스 관리
- [ ] 무료 체험 (7일 또는 3회 처리)
- [ ] 라이센스 키 입력 및 로컬 검증
- [ ] 서버 인증 (온라인 시 자동 검증)
- [ ] 오프라인 모드 (7일간 오프라인 허용)
- [ ] 라이센스 비활성화 (기기 변경 시)

### 2.7 설정
- [ ] 기본 출력 폴더 설정
- [ ] 마스터링 프리셋 저장/불러오기
- [ ] 처리 품질 설정 (빠름/표준/고품질)
- [ ] 언어 설정 (한국어/영어)
- [ ] 업데이트 확인

## 3. 비기능 요구사항

- 안정성: 오디오 처리 중 앱 크래시 없음 (Python 프로세스 분리)
- 성능: 3분 WAV 기준 30초 이내 처리 (표준 품질)
- 보안: 라이센스 키 로컬 암호화 저장
- 확장성: 마스터링 알고리즘 플러그인 형태로 교체 가능
- 이식성: macOS 10.14+, Windows 10+ 지원
